# Play Store Listing Assets

- `hi-res-icon-512.png` — the 512x512 "Hi-res icon" Play Console asks for on the
  Store presence > Main store listing page. Matches the in-app adaptive icon.

Still needed before submitting the listing (not generated here, since they
need real screenshots/marketing copy):

- At least 2 phone screenshots (min 320px, max 3840px on the longest side).
- A 1024x500 feature graphic.
- Short description (≤80 chars) and full description (≤4000 chars).
- A hosted Privacy Policy URL — see `/PRIVACY_POLICY.md` in the repo root for
  ready-to-publish text (host it as a GitHub Pages page, a gist, or any web
  page, then paste that URL into Play Console > App content > Privacy Policy).
